### 🏪 About The Project

**Manoj Automobile** is a full-stack web application built for a real-world car service workshop located in **Dabri/Dwarka, Delhi** with **30+ years of expertise**. The platform combines a stunning customer-facing website with a powerful admin dashboard for complete business management.

> *"We only recommend work your car actually needs."* — **Manoj Ji, Owner**
