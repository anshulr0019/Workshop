<!-- Quick Start -->
<div align="center">
<h2>Get Started.</h2>
<br/>
</div>

<pre><code># Clone the repository
git clone https://github.com/yourusername/manoj-automobile.git

# Navigate to project
cd manoj-automobile

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build</code></pre>

|---------|--------|
